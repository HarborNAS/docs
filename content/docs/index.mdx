## Ask a question

Use [Community Q&A](https://github.com/HarborNAS/community/discussions/categories/q-a) for setup and usage questions, or [open a configuration question](https://github.com/HarborNAS/community/issues/new?template=question.yml). You can report HarborOS problems here without knowing which source repository owns them.

The [official Download Center](https://harboros.ai/pages/download-center) provides the Nexus hardware manual, firmware, utilities, and HarborOS installation image. The [Guidance section](https://harboros.ai/blogs/guidance) includes application tutorials. Detailed storage and networking guides are still being expanded; if your topic is not covered, please ask rather than guessing at settings.
