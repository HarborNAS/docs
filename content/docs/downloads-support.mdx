## Official Download Center

The [HarborOS Download Center](https://harboros.ai/pages/download-center) provides the user manual, system image, firmware, and hardware utilities. Use that page to check for newer files before downloading.

## User manual

[Download the Nexus AI Station User Manual (PDF)](https://cdn.shopify.com/s/files/1/0655/1647/0366/files/Nexus_AI_Station_-_User_Manual.pdf?v=1775805723).

This 60-page hardware manual includes English, Chinese, Spanish, German, French, and Japanese sections. It covers package contents, chassis and ports, memory, SSD, GPU and HDD installation, power connections, startup, and BIOS access. The English section is on PDF pages 4–12; Chinese is on pages 13–21.

For first power-on, open [PDF page 11](https://cdn.shopify.com/s/files/1/0655/1647/0366/files/Nexus_AI_Station_-_User_Manual.pdf?v=1775805723#page=11). HarborOS configuration questions can be raised through [Configuration help](/docs/configuration-help).

## Software guides

The official site's [Guidance section](https://harboros.ai/blogs/guidance) includes an [Ollama installation guide with screenshots](https://harboros.ai/blogs/guidance/ollama-installation-guide). See [Application guides](/docs/application-guides) for the current guide and community help.

## Contact support

- **Hardware, orders, and private support:** email [support@harborinno.com](mailto:support@harborinno.com), or use the [official contact form](https://harboros.ai/pages/contact-us).
- **Public configuration questions:** [Community Q&A](https://github.com/HarborNAS/community/discussions/categories/q-a) or the [question form](https://github.com/HarborNAS/community/issues/new?template=question.yml).
- **HarborOS bugs:** [Bug report form](https://github.com/HarborNAS/community/issues/new?template=bug_report.yml).
- **Warranty and returns:** [Warranty policy](https://harboros.ai/pages/warranty-policy) and [Return & Refund](https://harboros.ai/pages/return-refund).

Send order numbers and serial numbers privately to the support team when needed; do not include them in public issues.
