## Submit a report

1. [Search existing reports](https://github.com/HarborNAS/community/issues?q=is%3Aissue), including closed issues.
2. Sign in to GitHub and [open the Bug report form](https://github.com/HarborNAS/community/issues/new?template=bug_report.yml). You can also visit **HarborNAS/community → Issues → New issue → Bug report**.
3. Describe the problem, the steps that lead to it, and what you expected to happen. If it is intermittent, describe when it occurs.
4. Add your HarborOS version/build, server model, and relevant browser or application details if known.
5. Submit the report and continue the conversation on that issue.

You do not need to identify the responsible source-code repository. Screenshots and logs are optional; remove credentials and personal information before uploading them. English and Chinese reports are welcome.

## Follow progress

Use **Subscribe** on the issue to receive updates according to your GitHub notification settings. Maintainers may ask for details, classify the report, or link it to the relevant project. Add requested information to the original report rather than opening a new issue.

## Other feedback

For usage questions, see [Configuration help](/docs/configuration-help). For improvements, [submit a feature request](https://github.com/HarborNAS/community/issues/new?template=feature_request.yml) or [discuss an idea](https://github.com/HarborNAS/community/discussions/categories/ideas).
