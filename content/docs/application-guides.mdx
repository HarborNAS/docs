## Install Ollama

The official [Ollama Installation Guide](https://harboros.ai/blogs/guidance/ollama-installation-guide), published June 17, 2026, includes screenshots of the app catalog and installation settings.

It shows how to open the application catalog, refresh its entries, find Ollama, and configure its installation. It also identifies the CPU, memory, and NVIDIA GPU settings in the illustrated form. Use the original guide's screenshots to identify those controls.

If your installed HarborOS version shows different options or installation fails, [ask a configuration question](https://github.com/HarborNAS/community/issues/new?template=question.yml). Include your HarborOS build, GPU model if relevant, and the error message.
