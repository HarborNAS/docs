## Where to ask

- [Community Q&A](https://github.com/HarborNAS/community/discussions/categories/q-a): questions and advice from the community.
- [Configuration question form](https://github.com/HarborNAS/community/issues/new?template=question.yml): a question you want to track in Issues.

Sign in to GitHub to submit a question. English and Chinese are welcome. Search existing issues and discussions first; if your problem is already covered, add relevant details to that conversation.

## What to include

Describe what you want to accomplish, what you have tried, and what happened. Include your server model and HarborOS version/build if available. If you cannot find the version, write "unknown"; this should not prevent you from asking for help.

For networking questions, describe how the server and client are connected, including separate networks, VPNs, or guest Wi-Fi if relevant. For file-sharing questions, include the client operating system, sharing protocol, and the error message. For application questions, include the application name and version if known. For storage questions, describe the disks and existing configuration, and whether important data is already on them.

Screenshots and logs are optional. Remove credentials, access tokens, serial numbers, and personal information before posting. Issues and discussions are public.

## Follow the answer

Reply in the original issue or discussion when more information is requested. Use GitHub's **Subscribe** option to follow updates. In Q&A, mark a helpful reply as the answer when it solves your question.

If you suspect a bug but are unsure, either a question or a [bug report](/docs/reporting-bugs) is fine. Explain the symptoms rather than opening duplicate reports.
