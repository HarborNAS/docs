## Find the server address

Connect your server and your computer to the same local network for the first access. Use the connection details supplied with your server. If you do not know its address, look for the server in your router's connected-device or DHCP lease list. Some devices also display their address on a local screen.

Open the management URL supplied with your server in a browser. If you only have an IP address, confirm the protocol and port from the supplied setup instructions. Do not assume a default password or a particular management port.

## If the interface does not open

1. Check that the server is powered on and that its network cable is connected.
2. Confirm that the address belongs to your server and has not changed after a restart.
3. Check whether your computer is on a guest network or another network that cannot reach the server.
4. Record the exact browser error and whether the problem occurs from another device on the same network.

For help, [open a configuration question](https://github.com/HarborNAS/community/issues/new?template=question.yml). Share the relevant network arrangement and error message, but do not post passwords or expose your management interface to the internet just to troubleshoot it.

## Before changing configuration

Keep a separate backup of important data. Record the current settings and change one thing at a time so you can explain what changed. If an action mentions formatting, erasing, or replacing storage, confirm its effect on your existing data before continuing.

See [Configuration help](/docs/configuration-help) for what to include when asking about storage, networking, or applications.
