# HarborOS documentation style

This site helps HarborOS owners find setup guidance, downloads, and support while configuring their server.

## Direction

Use `professional-saas` for the resource homepage and `editorial-lab` for reading guides. Match the existing Harbor storefront identity, with a white reading surface, black brand header, purple actions, and simple rectangular resource panels.

Reference: https://harboros.ai/pages/download-center, inspected October 3, 2026. The original logo is referenced from the storefront CDN. Do not recreate the logo or copy the storefront's page implementation.

## Tokens and components

- Primary action: `#6715ff`; hover `#5010cf`; white button text.
- Header/footer: `#18181a` with white text; secondary footer text `#b9b9b9`.
- Reading surface: `#ffffff`; resource panels `#f2f2f2`; body text `#171717`.
- Body font: Figtree. Heading and action font: Jost, weight 600.
- Buttons: rectangular, at least 50px high, uppercase labels with restrained letter spacing.
- Cards: rectangular gray surfaces, no nested cards or decorative shadows.
- Navigation: direct links to Docs, Downloads & Support, Guides, and Community. Mobile menu contains the same links.
- Dark reading theme is optional; first visits use the light theme to match the official support pages.
- Tables, search, and sidebar use the same brand tokens while keeping normal documentation density.

## Acceptance

Check the homepage and downloads guide at desktop, tablet, and 390px mobile widths. Downloads must be reachable from both the homepage action and the navigation menu. Confirm logo legibility, keyboard focus, no horizontal page overflow, and readable tables. Keep the official website, support, and community links available in the footer.
